# CLAUDE.md — Musa Landing Page

## Sobre el Proyecto
Landing page oficial de **Musa**, la marca personal de Kelsey Arias.
Especializada en Fire Performance & Flow Arts para eventos exclusivos.
- **Dominio:** musacr.com
- **Repositorio:** https://github.com/KelseyA98/musa-landing
- **Hosting:** GitHub Pages + Cloudflare

## Identidad de Marca
- **Tono:** Elegante, místico, sofisticado. Nunca genérico ni masivo.
- **Posicionamiento:** High-Ticket Performance — no es un show de fuego común, es una experiencia de arte en movimiento.
- **Audiencia:** Organizadores de bodas de lujo, festivales premium, empresas para activaciones corporativas exclusivas.
- **Servicios:** Shows de fuego, Performance LED y Seda, Workshops de Movimiento.

## Paleta de Colores
- `#000000` — Misterio (fondo principal)
- `#2F4F4F` — Estructura Nocturna (teal)
- `#DC143C` — Pasión Visceral (crimson)
- `#FF8C00` — Energía Juguetona (naranja)
- `#B8860B` — Magnetismo Old Gold (dorado)
- `#B57F50` — Ritual (copper)

## Reglas de Diseño
- Colores oscuros con acentos cálidos de la paleta oficial.
- Tipografía: Cormorant Garamond + Cinzel + Raleway.
- Imágenes y videos deben ser protagonistas.
- Nunca usar lenguaje genérico — usar lenguaje evocador.

## Reglas Técnicas y de Seguridad
- No hardcodear datos sensibles ni API keys en el código.
- Sanitizar cualquier input de formularios.
- El sitio debe cargar rápido — optimizar imágenes siempre.
- Compatible con móviles (mobile-first).
- Accesible: contraste adecuado, textos alternativos en imágenes.
- Todos los links externos tienen rel="noopener noreferrer".

## Stack
- HTML / CSS / JavaScript puro
- Sin frameworks innecesarios
